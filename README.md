## Current page foundation

- The homepage has a moving featured-story slideshow and six editorial features. Hovering, focusing, or tapping a park location changes its image and description.
- Visit: source map, downloadable PDF, directions, transit, parking, and park policies.
- Park: overview and direct links to the existing City facility websites. The park landscape has its own Foundation page; separate duplicate facility pages are not generated.
- Foundation: mission, vision, work, board, staff, and partner logos, with distinct destinations for initiatives, giving, supporters, and volunteering.
- Initiative and story templates: lead, image, rich text with headings, and links.
- What’s On has Upcoming, Archive, and Calendar views with Organization and Type filters. Single-day events, inclusive exhibition spans, and weekly series use Los Angeles calendar dates.
- News opens with a featured story above a three-column index. Readers can filter by organization and browse older stories.
- Search opens in the navigation on the current page. Existing search URLs open the same field and results on the homepage.

The **History / Timeline** page renders an ordered set of milestones. Editors can create it from the Studio creation menu and edit each date label, description, and photograph.

## Sanity content

`studio/schemaTypes` is the schema source of truth:

- **Homepage** (`homePage` singleton): hero stories, anniversary, content/place references, quote, and milestones.
- **Site settings** controls navigation, the homepage sunset label and city-run wording, contact details, social links, footer copy, land acknowledgment, donation links, newsletter form settings, and legal links. The header calculates sunset for the current date at Olive Hill in Los Angeles time.
- **Pages**: standard, Visit, Foundation, initiative, or History / Timeline template; summary, image and a rich-text body. Headings structure the page. The relevant templates also have editable milestones, directory entries, or annual giving levels.
- **Park locations**: an official `website` destination takes precedence in cards, search, and venue links.
- **Events** record the organization, type, Los Angeles start and end times, optional weekly repeat-until date, photographs, ticket link, and body.
- **News** records the organization, publication date, photographs, homepage link caption, summary, and body.

Images support a caption, crop, and focal point. The website uses the caption as the image’s alt text. Singletons are pinned in Studio. Public frontend reads use the **published** perspective, without an API token in the browser. GROQ results are generated by Sanity TypeGen. `defineLive` / `SanityLive` invalidate published content; draft mode and Presentation require a dedicated Viewer-token setup later.

```sh
npm run typegen       # Schema extraction + generated GROQ / TypeScript contracts
npm run schema:deploy
```

Commit `studio/schema.json` and `web/sanity.types.ts`; do not hand-edit generated types. The Sanity connector cannot access this project's organization with its currently connected account; the authenticated local Sanity CLI works and is used for schema / Studio deployment. Localhost and 127.0.0.1 on ports 3047 and 3048 are configured as CORS origins.

## Editing and preview

The production dataset contains published reference targets and editable review drafts. Open **Support the park** for the Foundation directory, initiatives, giving, year-by-year acknowledgments and volunteer opportunities. **History / Timeline** opens the long chronology. **Organizations and colors** controls the shared color pairs. Select an organization on its events, articles, places and hero slides.

The protected Vercel Preview reads Sanity’s drafts perspective with an environment-scoped Viewer token. Save a change in Studio and refresh the corresponding page. Local development uses the same behavior when `BARNSDALL_PREVIEW=true` and `SANITY_API_READ_TOKEN` are set in the ignored `web/.env.local`. Keep the token server-only. The production deployment reads published documents.

The dates and giving levels are staging content. When adding new references, publish their targets before publishing the referring document.

## Design and assets

The supplied interface plates determine the desktop layout, header overlays, feature crops and type scale. Their oversized display lettering uses the supplied project’s Aline Gothic. Barnsdall High is available for leads and the supplied Barnsdall Low provides the display fallback. Publisher Rounded Slab and Publisher Sans provide the text and captions.

The licensed Publisher webfonts are included in `web/src/fonts/`.

Upload original or neutral source photos in Studio. The site derives organization duotones in the browser using a CSS filter, with additional artwork presets for homepage slides and news. Logos, maps and archive photos can retain their original colors. The caption also supplies the image’s alt text. Editors can crop images and set focal points.

```sh

npm run deploy -w studio -- --url barnsdall-art-park-foundation --yes --schema-required
```

Add each website origin to Sanity CORS. Configure `NEXT_PUBLIC_SITE_URL` for a real production launch and the hosted `NEXT_PUBLIC_SANITY_STUDIO_URL`. Frontend and Studio deploy independently; schema deployment does not publish editorial content. See `docs/content-handoff.md` for the remaining launch inputs.
