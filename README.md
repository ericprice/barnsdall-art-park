## Current page foundation

- The homepage has a moving featured-story slideshow and an ordered selection of editorial features. Hovering, focusing, or tapping a park location changes its image and description.
- Visit: source map, downloadable PDF, directions, transit, parking, and park policies.
- Park: overview and direct links to the existing City facility websites. The park landscape has its own Foundation page; separate duplicate facility pages are not generated.
- Foundation: mission, vision, work, board, staff, and partner logos, with distinct destinations for initiatives, giving, supporters, and volunteering.
- Initiative and story templates: lead, image, rich text with headings, and links.
- What’s On has Upcoming and Archive views with an Organization filter. Single-day events, inclusive exhibition spans, and weekly series use Los Angeles calendar dates.
- News opens with a featured story above a three-column index. Stories appear in date order, including external partner news.
- Search opens in the navigation and shows up to five matches as you type. Submit the search to open a dedicated results page.

The **History / Timeline** page renders an ordered set of milestones. Editors open the canonical chronology under Pages → History and select which milestones appear on the homepage.

## Sanity content

`studio/schemaTypes` is the schema source of truth:

- **Homepage** holds featured slides, the anniversary callout, Explore photographs, and featured items with optional artwork and caption overrides.
- **Pages** holds narrative pages and their layouts. Sections support prose, columns, accordions, and template-specific content. The Foundation directory and History milestones have structured editors.
- **Park locations** holds each facility’s website or its managed page content.
- **What’s On** holds events, Los Angeles schedules, optional weekly recurrence, ticket links, and images.
- **News** holds on-site stories, promotions, and external partner stories. Display date controls chronological order.
- **Organizations** defines the color pairs. **Site settings** holds navigation, legal page references, sitewide quotes, and footer content.

Images have separate alternative text and captions, a decorative option, crop, and focal point. Public frontend reads use the **published** perspective, without an API token in the browser. GROQ results are generated by Sanity TypeGen. `defineLive` / `SanityLive` invalidate published content; draft mode and Presentation require a dedicated Viewer-token setup later.

```sh
npm run typegen       # Schema extraction + generated GROQ / TypeScript contracts
npm run schema:deploy
```

Commit `studio/schema.json` and `web/sanity.types.ts`; do not hand-edit generated types. The Sanity connector cannot access this project's organization with its currently connected account; the authenticated local Sanity CLI works and is used for schema / Studio deployment. Localhost and 127.0.0.1 on ports 3047 and 3048 are configured as CORS origins.

## Editing and preview

The production dataset contains published reference targets and editable review drafts. Open **Pages → Support the park** for Foundation pages and **Pages → History** for the chronology. Editors can choose a site page in link fields or enter a URL or fragment. [Editorial handoff](docs/content-handoff.md)

The protected Vercel Preview reads Sanity’s drafts perspective with an environment-scoped Viewer token. Save a change in Studio and refresh the corresponding page. Local development uses the same behavior when `BARNSDALL_PREVIEW=true` and `SANITY_API_READ_TOKEN` are set in the ignored `web/.env.local`. Keep the token server-only. The production deployment reads published documents.

The dates and giving levels are staging content. When adding new references, publish their targets before publishing the referring document.

## Design and assets

The supplied interface plates determine the desktop layout, header overlays, feature crops and type scale. The site uses Barnsdall Low for display type and Barnsdall High for leads. Publisher Rounded Slab is used for body text and display glyph fallback. Captions and footer fine print share the `small-text` mixin, which uses Publisher Rounded Sans at 0.875 times the body size with 0.02em letter spacing.

The licensed Publisher webfonts are included in `web/src/fonts/`.

Upload original or neutral source photos in Studio. The site derives organization duotones in the browser using a CSS filter, with additional artwork presets for homepage slides and news. Logos, maps and archive photos can retain their original colors. Captions and alternative text are edited separately. Editors can crop images and set focal points.

Vercel reserves the `production` branch for builds that read published content. At launch, remove the temporary review redirect in the project’s Routing Rules and configure the official domain. To deploy a manual preview, run the Vercel command below from the monorepo root.

```sh
npx vercel deploy --yes --scope studioericprice --project prj_GOCGgfVDZxcerrJPTGKdtWETPzUS --environment preview
npm run deploy -w studio -- --url barnsdall-art-park-foundation --yes --schema-required
```

Add each website origin to Sanity CORS. Configure `NEXT_PUBLIC_SITE_URL` for production canonicals, robots and the sitemap. Preview deployments disallow crawling. Run `npm run check:published` to verify public content before launch. Frontend and Studio deploy independently; schema deployment does not publish editorial content. See `docs/content-handoff.md` for the remaining launch inputs.
