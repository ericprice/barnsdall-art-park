# Barnsdall website

The Next.js frontend uses local Barnsdall and Publisher fonts and reads content from the standalone Sanity Studio. With Node 24, run the following command from the repository root.

```sh
npm run dev:web
```

Open [the local website](http://127.0.0.1:3047). The [project README](../README.md) covers environment variables, both development servers, draft preview, tests and deployment.
